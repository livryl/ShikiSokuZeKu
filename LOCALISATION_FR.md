# Version française — Shiki Soku Ze Ku v1.01

Ce document est une traduction communautaire et peut ne pas toujours refléter la version la plus récente du projet.
Pour obtenir les informations les plus à jour, veuillez consulter le fichier README.md.

###Télécharger https://github.com/livryl/ShikiSokuZeKu/releases/tag/v1.01FR

Application originale : **2026 ATF Livryl**, <https://x.com/ATFzwei>.

Cette version traduit les commandes, aides, messages, erreurs, commentaires et docstrings des modules Python, le JavaScript associé, les huit guides, le fichier de présentation et les titres de 26 nœuds dans les workflows. Le nom de l'application et son logo calligraphié sont conservés.

Les noms de modèles, classes de nœuds, connexions, valeurs numériques et identifiants d'API restent ceux de l'application. Les prompts exemples et les consignes internes destinées aux modèles peuvent rester en anglais pour préserver leur usage. Les recherches de tags japonais et la reconnaissance des dialogues cités sont conservées. La localisation n'étend pas les langues prises en charge par Irodori-TTS.

Le lanceur start.bat est destiné à Windows et ses messages ont été traduits. Le lanceur Linux de l'installation locale est fourni séparément de cette archive pour ne pas imposer de chemins propres à une machine.

L'archive ne contient ni environnement virtuel, ni modèles téléchargés, ni résultats, ni paramètres personnels. Lors d'une intégration à une installation existante, certains paramètres enregistrés utilisent des libellés traduits comme valeurs : formats d'image, modes de taille I2I et proportions vidéo. Sauvegardez les paramètres et migrez ces valeurs si nécessaire.
